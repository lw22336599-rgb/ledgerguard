Hi Arc builders — sharing a non-custodial USDC payment link demo on Arc Testnet.

**LedgerGuard** — send or receive USDC with a simple link (no custody, no private keys):

• Get paid: https://ledgerguard-gules.vercel.app/guard/create
• Pay a link: https://ledgerguard-gules.vercel.app/pay
• Payer reviews amount / recipient / purpose before signing in their wallet
• APIs: preflight, evidence, x402 testnet — OpenAPI + MCP on GitHub

Arc Testnet only for Guard Links (test assets). Base Mainnet x402 is a separate live demo at https://ledgerguard-gules.vercel.app/canary.
